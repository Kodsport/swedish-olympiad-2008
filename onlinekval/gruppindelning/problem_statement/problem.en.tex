\problemname{Group Division}
During a school field trip, the students are to be divided into different groups.
Naturally, the students want to be in the same group as their friends.
Write a program that, given the name of each student and who is friends with whom, computes the maximum number of groups the students can be divided into (if the students get their way).

\section*{Input}
The first line contains an integer: the number of students going on the trip ($2 \le n \le 100$).
Then follow $n$ lines, each containing the name of a student.
Each name is between $1$ and $20$ characters long and contains only the letters \texttt{A-Z}.
All students have different names.

Then follows a line with an integer: the number of friend pairs ($1 \le m \le 4950$).
Finally, $m$ lines follow containing the friend pairs.
For each pair, two names are given on the same line, separated by a space.

\section*{Output}
The program should output a single line with one integer: the maximum number of groups the students can be divided into.
